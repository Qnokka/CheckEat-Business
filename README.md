# CheckEat! For Business
### Integrated Dietary Information Application – For Business Users

CheckEat is designed to provide comprehensive ingredient information for individuals with dietary restrictions such as allergies, vegetarianism, and halal.  
It aims to expand food choices for foreign visitors in Korea and promote a safe dining culture. This repository is dedicated to the business-user version of the application, which facilitates the input of menu data.

<br>

### 📌 Key Features
- **Easy Menu Registration**: Simplify menu registration using OCR inference and LLM analysis powered by Azure AI models.  
- **Intuitive UI/UX**: Provides a user-friendly interface built with SwiftUI.  
- **Real-time Data Processing**: Menu data is processed in real-time for fast updates.
